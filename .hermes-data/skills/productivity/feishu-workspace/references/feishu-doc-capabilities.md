# Feishu Document & Drive Capabilities

Summary of available operations when using the `feishu_doc` and `feishu_drive` toolsets.

## Doc (文档)
- Create, read (structured blocks), update (insert/delete/replace blocks)
- Get metadata (title, timestamps, owner)
- Delete, search, comments, collaborative editing

## Sheet (电子表格)
- Create, manage worksheets (add/delete/rename/copy)
- Cell read/write with styles
- Formulas, data validation, filtering/sorting
- Merge/unmerge cells, protect ranges

## Base (多维表格)
- Create, manage tables
- Field management (multiple types)
- Record CRUD with batch operations
- Views (table, kanban, etc.), forms, permissions

## Drive (云盘)
- File CRUD: upload, download, delete, copy, move
- Folder management: create, list, rename, delete
- Permissions: set/get/revoke for members/departments/groups
- Sharing: create/delete share links with password/expiry
- Recycle bin, comments, version management

## Wiki (知识库)
- Create knowledge spaces
- Node management: add/move doc or folder nodes
- Search, permissions
